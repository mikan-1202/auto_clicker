## 公開直前の確認

1. アイコンの権利とアプリ本体の公開ライセンスを決定し、その根拠を残す。
2. `uv run --locked python tools/check_publication.py`を実行する。新たな変更をコミットした後も再実行する。
3. `git status --short`と公開対象のブランチ・タグを確認する。匿名化前の履歴を再取り込みしない。
4. 公開先に既存の未加工履歴がある場合は別途対応を計画する。このローカル作業だけでは外部コピーの状態を確認できない。
5. EXEを公開する場合は、別PC・保存読込・インストールを含む未実施項目と、同梱ライセンス対応を終える。

`.portfolio-backup/`には匿名化前の個人情報が残っています。作業フォルダー全体をZIP化して公開しないでください。Git管理された公開用ファイルを対象にしてください。既存の`build/`・`dist/`・過去の配布物は、今回検査したEXEとは別です。

検査は既知パターンを検出する補助であり、任意の個人情報・トークン・権利問題を完全に判定するものではありません。除外ファイルは意図して検査対象外とし、値そのものはログに出しません。雛形ファイルにも実際の秘密情報を記入しないでください。
