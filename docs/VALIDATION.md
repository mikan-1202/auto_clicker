## 手動確認手順

1. 空のメモ帳を入力先にして`examples/type_a_twice.json`を実行し、2回の入力後に再度開始できることを確認する。
2. 長い押下時間・待機間隔を設定し、停止キーで止める。キーが押されたままにならないことを確認する。
3. 長い待機中にアプリを閉じ、プロセスが終了することを確認する。
4. クリック座標、左右ボタン、編集、ドラッグ、ホットキー変更を確認する。
5. EXE版とインストール版でも同じ手順を行う。

これらの手動手順は今後の確認用であり、実施済みという意味ではありません。
