# AutoClicker アプリケーション仕様書

## 1. 概要

このドキュメントは、AutoClickerアプリケーションの仕様を定義します。
このアプリケーションは、ユーザーが設定した間隔や条件で自動的にマウスクリックを行うためのGUIツールです。

## 2. ファイル構成

プロジェクトは以下のファイルとディレクトリで構成されています。

```
.
├── main.py               # アプリケーションのエントリーポイント
├── icon.ico              # アプリケーションアイコン
├── auto_clicker/         # アプリケーションの主要なロジックを格納するパッケージ
│   ├── __init__.py
│   └── gui/
│       ├── __init__.py
│       └── main_window.py  # メインウィンドウのUIとロジック
└── README.md             # この仕様書
```

*(注: `auto_clicker` フォルダ内の構成は、`main.py` のimport文から推測される部分的なものです。)*

## 3. `main.py` の仕様

### 3.1. 概要

このスクリプトは、AutoClickerアプリケーションを起動するためのエントリーポイントです。アプリケーションの初期化とメインウィンドウの表示を担当します。

### 3.2. 機能

-   **アプリケーションIDの設定**: Windows環境において、タスクバーアイコンが正しくグループ化され、カスタムアイコン(`icon.ico`)が表示されるように、`AppUserModelID` を設定します。この処理はWindows固有であり、他のOSではスキップされます。
-   **GUIの初期化**: `auto_clicker.gui.main_window` モジュールから `AutoClickerApp` クラスをインスタンス化し、メインウィンドウを生成します。
-   **アイコンの設定**: スクリプトと同じディレクトリに `icon.ico` が存在する場合、それをウィンドウのアイコンとして設定します。
-   **アプリケーションの実行**: GUIのイベントループを開始し、ユーザーからの入力を待ち受けます。

### 3.3. 実行方法

以下のコマンドでアプリケーションを起動します。

```bash
python main.py
```

## 4. `auto_clicker` パッケージの仕様 (推定)

このパッケージはアプリケーションの心臓部であり、GUIと自動クリックのコアロジックを分離して格納します。

*(注: 以下の内容は、一般的なアプリケーション設計に基づく推定です。正確な仕様は実際のコードに依存します。)*

### 4.1. `auto_clicker.gui.main_window`

-   **クラス**: `AutoClickerApp`
-   **概要**: Tkinterをベースにしたメインウィンドウを定義します。
-   **想定される機能**:
    -   クリック間隔（秒、ミリ秒）を入力するUIコンポーネント。
    -   自動クリックを開始/停止するためのボタン。
    -   クリックボタン（左/右）やクリックタイプ（シングル/ダブル）などを設定するための設定画面を呼び出すボタン。
    -   現在の状態（実行中/停止中）を表示するステータス表示。

### 4.2. `auto_clicker.core` (推定されるサブパッケージ)

-   **概要**: 実際の自動クリック処理やホットキーの監視など、バックグラウンドで動作するロジックを格納します。
-   **想定されるモジュール**:
    -   `click_thread.py`: GUIの応答性を維持するため、別のスレッドでクリック処理を実行するクラス。
    -   `hotkey_listener.py`: アプリケーションが非アクティブな状態でも開始/停止を切り替えられるよう、グローバルホットキーを監視するクラス。

## 5. 使い方

1.  `python main.py` を実行してアプリケーションを起動します。
2.  メインウィンドウでクリック間隔を設定します。
3.  「開始」ボタンをクリックするか、設定されたホットキーを押して自動クリックを開始します。
4.  「停止」ボタンをクリックするか、再度ホットキーを押して停止します。
